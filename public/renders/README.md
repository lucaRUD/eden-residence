# Eden Residence — Architectural Renders

This directory contains **19 unique JPEG images**, renamed for easy use in the Astro website.

Copy all `eden-residence-*.jpeg` images into your local project at `public/images/renders/`.
Reference images with `/images/renders/<filename>.jpeg`.

`image-manifest.csv` maps additional filenames to source images and suggests appropriate website use.
Images were copied byte-for-byte: no resizing or re-encoding.

One supplied additional image (`WhatsApp Image 2026-06-10 at 13.42.47 (2)(1).jpeg`) was an exact duplicate of an image in the original batch and has been excluded.

All renders retain SKY Block watermarks. Confirm usage rights and obtain approved publication assets before launch.
